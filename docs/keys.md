# Keyboard shortcuts

| Key | Action |
| --- | --- |
| d | Dashboard |
| m | Minions |
| j | Jobs |
| r | State results |
| s | SLS explorer |
| Up / Down (SLS explorer) | Select a local file or Salt-reported state |
| Shift+Tab / Enter (SLS explorer) | Focus and activate an action button |
| Esc | Return to the previous screen |
| h | History |
| l | Logs |
| e | Live Salt events |
| v | Run tracker for selected run |
| g | Compiled state graph |
| Ctrl+M | Fleet state matrix for the selected run |
| i | Recurring failure patterns |
| p | Slow-state analysis |
| Ctrl+U | Runner functions |
| Ctrl+O | Orchestration |
| Ctrl+T | Saved targets |
| c | Command runner |
| ! | Failures |
| f / Shift+F | Next / previous failure within state results |
| x (History) | Select baseline run; press again on another run to compare |
| Space (Events) | Pause or resume event display |
| End (Events) | Toggle follow mode |
| u / n (Graph) | Follow an upstream / downstream edge |
| o (Graph or States) | Open a state’s SLS source |
| f (Run tracker) | Jump to the next failed or non-returning minion |
| n (Run tracker) | Cycle failed states for the selected minion |
| o (Run tracker) | Open the selected minion’s failed state source |
| a (Graph) | Show full graph |
| Ctrl+R | Refresh current screen |
| ? | Help |
| q | Quit |
| t | Settings |
| : | Command palette |
| Tab / Shift+Tab | Move focus |
| Enter | Open selected row or submit input |
